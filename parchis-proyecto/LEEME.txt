PARCHIS - Proyecto Maven para NetBeans
Requiere JDK 17 o superior.

ABRIR EN NETBEANS
  File > Open Project... > seleccionar la carpeta "parchis-netbeans" (tiene icono de Maven) > Open Project.
  NetBeans descarga lo necesario la primera vez (necesita internet).

EJECUTAR
  Clic derecho en el proyecto > Run (o F6): abre la version grafica (MainGUI) con --demo.
  Para correr la consola: clic derecho sobre Main.java > Run File (Shift+F6).
  Para dados aleatorios: en pom.xml deja vacia la linea <exec.appArgs></exec.appArgs>.

JDK: si marca error de version, Project Properties > Build > Compile y elegir JDK 17+ (Tools > Java Platforms).
